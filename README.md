# Oryx POS

نظام نقطة المبيعات للمطاعم — Restaurant Point of Sale System

## تحميل التطبيق

### Android (APK)
[حمّل Oryx-POS-v1.0.8.apk](https://github.com/mohamed-adel674/pos-system/releases/download/v1.0.8/Oryx-POS-v1.0.8.apk)

### Windows (EXE)
[حمّل Oryx.POS.Setup.1.0.8.exe](https://github.com/mohamed-adel674/pos-system/releases/download/v1.0.8/Oryx.POS.Setup.1.0.8.exe)

## المميزات

- نقطة بيع (POS) — طلب داخلي / تيك أواي / ديليفري
- شاشة مطبخ (KDS) — عرض الطلبات على شاشات المطبخ
- إدارة المخزون — تتبع المخزون وتنبيهات نفاد الصلاحيات
- المحاسبة ودفتر اليومية — قيود يومية وحسابات تلقائية
- إدارة الرواتب والموظفين — حضور وانصراف وحساب الرواتب
- إدارة الورديات مع تتبع النقد — افتتاح وغلق ورديات مع تقرير مفصل
- طباعة فواتير حرارية — دعم طابعات 80mm و58mm
- نسخ احتياطي واستعادة — نسخ تلقائي ويدوي مع استعادة من Firebase
- صلاحيات وأدوار (RBAC) — 10 أدوار و54 صلاحية
- سجل تدقيق وأمان — تتبع كل التغييرات في النظام
- نظام التراخيص — تفعيل الجهاز مع إدارة الأجهزة عبر Firebase
- تحديث تلقائي — تحديث التطبيق من داخل النظام
- واجهة عربية بالكامل — دعم كامل للغة العربية والثيم الداكن

## التثبيت

### Android
1. حمّل ملف APK
2. افتحه على جهاز Android
3. اسمح بالتثبيت من مصادر غير معروفة
4. أدخل رابط السيرفر وبيانات التسجيل

### Windows
1. حمّل ملف Setup
2. ثبّت النظام (يتطلب صلاحيات المدير)
3. النظام يشتغل بشكل مستقل (PHP + MySQL مدمجين)
4. افتح التطبيق وابدأ العمل

## الحد الأدنى للمتطلبات

### Android
- Android 7.0+
- 2GB RAM
- اتصال بالإنترنت

### Windows
- Windows 10+
- 4GB RAM
- 1GB مساحة فارغة

## التقنيات

- **Backend:** Laravel 11 + PHP 8.2
- **Frontend:** Vue 3 + Inertia.js
- **Database:** MySQL / MariaDB
- **Desktop:** Electron 33
- **Mobile:** Capacitor (Android)
- **License:** Firebase Firestore
- **Printing:** Node.js TCP Server
